# Juspross Core Interface

Quiero que construyas una interfaz web extremadamente avanzada llamada "Juspross".

IMPORTANTE:

No quiero un dashboard SaaS convencional.

No quiero una página web genérica de inteligencia artificial.

No quiero el típico diseño de tarjetas, botones redondeados, fondo negro con neón y textos futuristas.

Quiero que Juspross se sienta como un SISTEMA OPERATIVO DE INTELIGENCIA ARTIFICIAL DEL FUTURO.

La experiencia visual debe transmitir:

- inteligencia

- tecnología extremadamente avanzada

- velocidad

- precisión

- futuro

- exclusividad

- poder

- sofisticación

- profundidad

- misterio tecnológico

- sensación de estar interactuando con una IA extremadamente avanzada

La inspiración visual general debe combinar:

1. una superficie tridimensional formada por miles de partículas que crea ondas y formas;

2. una ciudad digital futurista vista en perspectiva;

3. circuitos tridimensionales;

4. redes neuronales;

5. partículas luminosas;

6. estructuras de datos;

7. interfaces holográficas;

8. profundidad espacial;

9. iluminación volumétrica;

10. tecnología avanzada de ciencia ficción.

Sin embargo, NO quiero copiar ninguna de las imágenes de referencia literalmente. Debes crear una identidad visual original para Juspross.

==================================================

1. CONCEPTO GENERAL

==================================================

La interfaz debe sentirse como si el usuario hubiera entrado directamente en el sistema operativo de una inteligencia artificial llamada Juspross.

La pantalla principal debe ser un entorno 3D inmersivo.

El usuario no debe sentir que está "visitando una página web".

Debe sentir:

"Estoy dentro de Juspross."

La interfaz debe tener un elemento central extremadamente importante:

EL NÚCLEO DE JUSPROSS.

Este núcleo representa físicamente a Juspross dentro de la interfaz.

Debe estar basado directamente en el logo proporcionado.

El logo proporcionado es el símbolo oficial de Juspross y NO debe ser reemplazado por un icono genérico.

==================================================

2. LOGO DE JUSPROSS

==================================================

Utiliza el logo proporcionado como referencia visual y geométrica principal.

El logo tiene:

- forma circular

- curvas fluidas

- segmentos azul/cian

- segmentos azul oscuro

- estructura dinámica

- sensación de movimiento

- apariencia tecnológica

NO quiero simplemente colocar el PNG del logo en el centro.

Quiero transformar visualmente el logo en una estructura tridimensional de partículas.

El logo debe convertirse en:

UN LOGO 3D FORMADO POR PARTÍCULAS.

Cada parte del logo debe estar compuesta por múltiples partículas independientes.

Las partículas deben tener:

- profundidad 3D

- pequeñas variaciones de tamaño

- movimiento lento

- pequeñas oscilaciones

- iluminación propia

- ligera dispersión

- comportamiento orgánico

- separación entre partículas

A distancia, las partículas deben formar claramente el logo de Juspross.

De cerca, debe verse que el logo está formado por cientos o miles de pequeñas partículas independientes.

El logo debe conservar su identidad y ser reconocible.

NO deformar tanto la geometría que deje de parecer el logo original.

==================================================

3. NÚCLEO 3D

==================================================

El núcleo debe ser el protagonista de la pantalla principal.

Debe estar aproximadamente en el centro de la experiencia.

Debe existir una sensación clara de profundidad.

El núcleo no debe ser una esfera genérica.

Debe tener la FORMA DEL LOGO DE JUSPROSS.

La estructura debe sentirse tridimensional.

Las partículas deben estar distribuidas también en profundidad, no solamente sobre una superficie plana.

Debe existir un ligero movimiento permanente.

Las partículas pueden desplazarse unos pocos píxeles alrededor de su posición original, manteniendo la forma general del logo.

El movimiento debe ser:

- lento

- elegante

- orgánico

- tecnológico

- hipnótico

- nunca caótico

El núcleo debe parecer una estructura energética contenida.

==================================================

4. COLORES DEL NÚCLEO

==================================================

Utiliza principalmente los colores originales del logo:

- azul/cian brillante

- azul profundo

- azul oscuro

No reemplazar la identidad cromática.

Las partículas deben heredar los colores de las diferentes partes del logo.

El azul/cian debe utilizarse para las zonas correspondientes del logo.

El azul oscuro debe mantenerse en las zonas correspondientes.

Puede existir una pequeña cantidad de variación tonal para crear profundidad.

También puede haber iluminación muy sutil en:

- turquesa

- azul eléctrico

- violeta azulado

Pero estos colores secundarios deben ser MUY sutiles.

No quiero una explosión de colores.

La identidad principal debe seguir siendo azul/cian/azul oscuro.

==================================================

5. ESTADO IDLE

==================================================

Cuando Juspross esté esperando:

El núcleo debe permanecer visible.

Las partículas deben moverse lentamente.

La estructura debe respirar visualmente.

Debe existir una deformación mínima y orgánica.

El núcleo puede tener una pulsación extremadamente sutil.

No quiero que parezca estático.

Tampoco quiero una animación exagerada.

Debe parecer que Juspross está "vivo".

==================================================

6. ESTADO LISTENING

==================================================

Cuando el sistema detecte:

"Hey Juspross"

debe entrar en modo LISTENING.

La transición debe ser visualmente impresionante pero elegante.

Las partículas del núcleo deben comenzar a reaccionar.

La energía alrededor del núcleo puede aumentar ligeramente.

Las ondas digitales del fondo pueden reaccionar de forma sutil.

Mostrar discretamente un estado:

LISTENING

o

ESCUCHANDO

La interfaz debe indicar visualmente que Juspross está escuchando.

Debe existir transcripción en tiempo real de lo que el usuario está diciendo.

La transcripción no debe ocupar una gran parte de la pantalla.

Debe aparecer de forma elegante cerca del núcleo o en una pequeña zona contextual.

==================================================

7. ESTADO THINKING

==================================================

Después de recibir la solicitud:

El núcleo debe cambiar a THINKING.

Las partículas deben comenzar a reorganizarse.

Pueden aparecer pequeños flujos de partículas alrededor del núcleo.

El fondo puede aumentar ligeramente su actividad.

Debe sentirse como si la IA estuviera procesando información.

No mostrar una simple rueda de carga.

NO usar un spinner genérico.

La actividad debe ser visual y tecnológica.

==================================================

8. ESTADO PROCESSING

==================================================

Cuando los agentes de Juspross estén trabajando:

El núcleo debe mostrar una actividad mayor.

Las partículas pueden comenzar a formar pequeños flujos.

Pequeños paquetes de luz/datos pueden viajar alrededor del núcleo.

El fondo puede mostrar circuitos o líneas de datos moviéndose lentamente.

El sistema debe comunicar:

"Juspross está trabajando."

==================================================

9. ESTADO SPEAKING

==================================================

Este es uno de los comportamientos más importantes.

Cuando Juspross esté respondiendo por voz:

EL NÚCLEO DEBE REACCIONAR A LA VOZ.

La forma del núcleo debe deformarse suavemente siguiendo la amplitud y ritmo del audio.

No quiero una simple barra de ecualizador.

Quiero que el LOGO COMPLETO DE PARTÍCULAS respire y se deforme suavemente.

Cuando Juspross habla más fuerte:

- mayor expansión

- mayor movimiento

- mayor energía

Cuando habla suavemente:

- movimiento reducido

La deformación debe ser:

- elegante

- orgánica

- fluida

- tridimensional

El logo siempre debe seguir siendo reconocible.

==================================================

10. ESTADO SUCCESS

==================================================

Cuando una tarea termine correctamente:

Crear una transición breve y elegante.

El núcleo puede emitir una onda de energía.

Las partículas pueden expandirse ligeramente y volver a su posición.

El color puede cambiar ligeramente durante un instante.

Después volver al estado normal.

No utilizar celebraciones exageradas.

==================================================

11. ESTADO ERROR

==================================================

Cuando exista un error:

NO cubrir toda la pantalla.

Mostrar una pequeña ventana contextual.

Por ejemplo:

JUSPROSS

SYSTEM ERROR

No se pudo completar la operación.

[REINTENTAR]

La interfaz puede utilizar temporalmente tonos:

- naranja

- rojo

- ámbar

pero de forma elegante.

El núcleo puede mostrar un cambio sutil de color.

==================================================

12. FONDO

==================================================

El fondo debe ser una experiencia 3D.

No utilizar una simple imagen de fondo.

Quiero un fondo generado/renderizado visualmente mediante elementos digitales.

Debe combinar:

- ondas de partículas

- redes neuronales

- circuitos

- ciudad digital

- perspectiva profunda

- partículas

- superficies tridimensionales

Debe existir una clara sensación de profundidad.

La cámara debe tener una perspectiva cinematográfica.

==================================================

13. ONDAS DE PARTÍCULAS

==================================================

Crear superficies tridimensionales formadas por partículas.

Estas superficies deben parecer ondas digitales.

Las ondas pueden extenderse hacia el horizonte.

Deben moverse lentamente.

No deben interferir con el núcleo.

El movimiento debe ser suficientemente sutil para no distraer.

Debe parecer una enorme superficie de datos viva.

==================================================

14. CIUDAD DIGITAL

==================================================

En algunas zonas del fondo pueden aparecer estructuras similares a una ciudad digital.

No quiero edificios realistas.

Quiero estructuras abstractas formadas por:

- bloques

- circuitos

- líneas

- columnas luminosas

- pequeños puntos

- datos

Todo debe estar integrado en el entorno.

Debe existir perspectiva.

Las estructuras cercanas pueden tener mayor definición.

==================================================

15. CIRCUITOS

==================================================

Agregar circuitos tridimensionales al entorno.

Pueden recorrer determinadas áreas del fondo.

No deben parecer circuitos de una placa electrónica tradicional.

Deben parecer circuitos de tecnología extremadamente avanzada.

Pequeños puntos de luz pueden desplazarse por las líneas.

==================================================

16. PARTÍCULAS DEL FONDO

==================================================

Utilizar pocas partículas flotantes.

No llenar toda la pantalla.

Deben existir zonas con mayor densidad y zonas casi vacías.

Esto ayuda a crear profundidad.

Las partículas deben ser pequeñas y discretas.

==================================================

==================================================

El entorno debe reaccionar ligeramente al movimiento del mouse.

No quiero un efecto exagerado.

Cuando el usuario mueva el cursor:

- las partículas pueden reaccionar ligeramente

- el entorno puede tener un pequeño efecto de parallax

- el núcleo puede reaccionar mínimamente

Todo debe ser sutil.

No exagerar.

El núcleo 3D formado por partículas es el corazón de toda la interfaz.

TODO debe construirse alrededor de él.

Cuando Juspross escucha:

el núcleo reacciona.

Cuando Juspross piensa:

el núcleo cambia.

Cuando Juspross procesa:

el núcleo muestra actividad.

Cuando Juspross habla:

el núcleo se deforma siguiendo su voz.

Cuando Juspross termina:

el núcleo vuelve a su estado normal.

Cuando ocurre un error:

el núcleo cambia sutilmente de color.

La interfaz debe sentirse como si el núcleo fuera la representación visual de la propia inteligencia artificial.

Construir la aplicación de forma modular y mantenible.

- UI

- partículas

- fondo 3D

- agentes

- actividad

- Shorts

- analytics

- autenticación

- comunicación con n8n

- configuración

- debug

No crear un único componente gigante.

Crear componentes reutilizables.

Preparar la arquitectura para que posteriormente pueda conectarse el backend real de Juspross.

54. IMPORTANTE SOBRE EL BACKEND

==================================================

NO inventar que Juspross ya está conectado.

La interfaz debe estar PREPARADA para conectarlo.

Crear una capa de integración claramente identificable.

Utilizar datos mock solamente para demostrar visualmente cómo funcionará la interfaz mientras no esté conectado n8n.

Debe ser fácil reemplazar los mocks por la comunicación real.

55. PERFORMANCE

==================================================

El entorno 3D debe estar optimizado.

Evitar crear miles de elementos DOM individuales si existe una solución gráfica más eficiente.

Utilizar tecnologías apropiadas para renderizado 3D y partículas.

Priorizar GPU cuando sea posible.

El núcleo debe funcionar de manera fluida.

El fondo debe degradarse elegantemente si el dispositivo tiene menor rendimiento.
